# ART_DIRECTION.md — 美術與渲染實證方向（追平並超越原版）

> 建立日期：2026-11-27（2026-11-27 經三方 1:1 遊戲內實機對照驗證後修訂）。
> 本文件記錄 OpenGraphics 與 2004 年原版 Locomotion 之間的畫面差距分析、M7 渲染與 PBR 貼圖的實測結論，以及後續最有效的美術提升方向。

---

## 1. M7 實測教訓：什麼有效、什麼在 64 px 等軸測下反效果

2026-11-27 實際將 `static_rig.py` 切為 Cycles 路徑追蹤、建立 20 組 512×512 實拍 PBR 貼圖並重算全數建築與產業後，以同地圖同鏡頭三方並排（`Vanilla` vs `Pre-M7 HEAD (EEVEE)` vs `Cycles + PBR`）實機比對，得到以下**關鍵經驗法則**：

### 1.1 驗證有效、應持續沿用的方向 ✅
1. **2D 地表／岩地使用大尺度實拍 PBR + 精確斜坡數學（`tools/gen/terrain.py`、`tools/g1.py`）**：
   - `OG_ROCK1`（`textures/pbr/ground_rock`）將原本的深藍泥巴徹底升級為清晰立體的高山灰花崗岩。
   - `g1.py` 放寬 `surface_smooth_mask`（`band_w = 5.8`）＋協調 `GRASS1`/`GRASSBR` 色溫，徹底消除草地菱形硬切邊。
   - `terrain.py` 的 16 次向量化二分法斜坡求解徹底根除 `slope 15` 直條紋破圖。
2. **幾何品質與防破圖機制（`ops.py`、`port_recipes.py`、`build_stations.py`、`build_blender_objects.py`）**：
   - `ops.py` 自動共面去重偏移（`_deconflict_boxes`）避免重疊面閃爍。
   - 機場跑道薄鋪面（`Z_PAVE = 0.25`）＋相連端點延伸消除 tile 暗縫，並移除停車大樓屋頂會變洋紅的 `company2` 車輛。
   - 高聳建築／產業統一使用 `size=400` 防止 sprite 頂部裁切。

### 1.2 在 64 px 等軸測 3D 建築上已證實不適用的方向 ❌
1. **512×512 實拍磚瓦 PBR 直接貼在小尺寸 3D 建築上**：
   - 遊戲內民宅僅 `30×20 px`，高頻實拍磚瓦縮小後低於奈奎斯特極限（單塊磚 `< 0.3 px`），經反鋸齒與降噪平均成毫無細節的粉白平滑色塊，遠不如 `_add_arch_shader` 刻意畫在 `1.5–2.5 px` 像素尺度的清晰磚縫與疊瓦。
2. **Cycles 單一主光＋`AgX`＋OIDN 降噪取代 EEVEE 4 燈＋`Standard`**：
   - `AgX` 壓縮飽和度與高光，導致銅綠圓頂、深藍灰石板瓦與暖木瓦褪成灰白粉彩；
   - 改回 `Standard` 後，Cycles 單主光硬影＋大尺度污漬貼圖仍讓暗面偏重、牆面與工業廠區顯得髒亂沉悶；
   - 反觀 **`Pre-M7 HEAD` 的 EEVEE 4 燈暖陽配置＋`Standard`＋`filter_size=0.75`＋像素尺度程序著色器（`_add_arch_shader` / `_add_ground_shader`）** 在 256 色等軸測下最明快、乾淨、清晰可讀。
3. **全域 4×4 Bayer 抖動量化（`quantize.py --dither`）**：
   - 在平滑斜屋頂產生細碎棋盤雜點，不如乾淨的零抖動調色盤色階俐落。

## 2. 後續真正能拉近並超越原版的美術方向

經三方對照（`Vanilla` vs `Pre-M7 HEAD`），現有乾淨 EEVEE 畫面的主要短板**不在渲染引擎**，而在以下四項設計與造型本身：

1. **住宅建築多樣性與造型豐富度（`BLDHOUS*`、`BLDHOU10–25`、`BLDALP*`）**：
   - 拉開同區住宅的屋頂色彩（深紅磚瓦、威爾斯藍灰板岩、暖褐木瓦、白牆／紅磚／黃磚交錯）、屋型變化（老虎窗、煙囪、門廊、側翼）與庭院微細節，徹底打破整街複製貼上感。
2. **地標產業與城鎮中心輪廓辨識度**：
   - 強化重要產業（農場、工廠、煉油廠、化工廠）的標誌性大輪廓與配色層次，避免全部灰褐單調。
3. **樹木品項與冠層自然度（`tools/gen/tree3d.py`）**：
   - 在維持 0.45× 寫實建築比例下，進一步豐富落葉樹（楓樹、橡樹、白樺）的枝幹輪廓與四季葉色自然度，補上原版森林與城鎮綠蔭的層次感。
4. **基礎設施細節（橋梁、車站、道路、車輛）**：
   - 持續優化機場停機坪與跑道標線、火車站玻璃雨棚明度，以及車輛的造型與配色質感。

## 3. 驗收標準

所有美術調整必須先以 **小規模 1:1 三方並排對照（`Vanilla` vs `HEAD` vs `新版`）** 經使用者肉眼確認「明確優於舊版」，才可批次重算全類別物件，並通過 V1（`tools/lint.py` 0 錯誤）與 V2（`tools/v2_smoke.sh`＋`title_compare` 截圖檢視）。
